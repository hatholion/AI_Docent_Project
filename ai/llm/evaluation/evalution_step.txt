질문 + 선택된 relic_label → Gold에서 relic_id로 변환
평가 JSON은 항목마다 query, relic_label, relevant_chunk_ids를 지정한다.
YAML의 rag.relic_label은 단일 질문 검색용이며, 평가 대상은 각 JSON 항목에서 정한다.
          │
          ▼
relic_id metadata 필터
          │
          ▼
해당 유물의 Top-K 청크
          ├── 사람이 라벨링한 relevant_chunk_ids와 비교
          │      └── Chunk Recall@1/3/5 (LLM 호출 없음)
          ▼
RAG context
          │
          ▼
LLM + visitor_type (test/child/general/expert)
  - ollama: 서버 호출
  - transformers + huggingface: 원본 모델을 양자화하여 CUDA 추론
  - transformers + local: 저장된 모델을 로컬에서 읽어 CUDA 추론
          │
          ▼
대상에 맞춘 도슨트 답변

visitor_type=test는 대상별 난이도 지시 없이 사용할 수 있으며
Retriever 평가에는 visitor_type이 전달되지 않는다.

양자화 모델 저장은 ai/rag/scripts/prepare_llm.py --config ... 로 수행한다.
저장 후 llm.source=local, llm.model=저장 폴더로 변경한다.
