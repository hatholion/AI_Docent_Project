# 로컬 LLM 3종 비교 결과

Golden Set: 유물 7개 × 질문 2개(재질/시대 확인, 국보·보물 지정 여부 확인) = 14문항.
`bon002789`, `jub000702`, `ssu001794`는 실제 지정문화재이고 나머지 4개는 아니라는 걸
이미 알고 있어서, "지정 여부" 질문은 hallucination(없는 사실을 지어내는지) 자동 탐지에도 씀.

## Hallucination 검증 (자동 탐지 + 직접 검토)

자동 탐지 결과를 그대로 쓰지 않고 실제 응답 원문을 전부 읽어서 검증함
(자동 탐지 자체도 "역사적"이 "사적" 키워드에 걸리는 등 오탐이 있어서 로직을 두 번 고침).

| 모델 | 자동 탐지 | 직접 검토 후 진짜 hallucination |
|---|---:|---|
| exaone3.5:7.8b | 1건 | **0건** — "확인 불가"라고 정직하게 답함(표현만 다소 애매) |
| llama3.1:latest | 2건 | **2건 확정** — 아래 참고 |
| qwen2.5-7b-quant-manual | 1건 | **0건** — 정답이었는데 문장이 나뉘어서 자동 탐지가 오탐 |

### Llama 3.1의 실제 hallucination 사례

- `duk000798`(청동촛대, 미지정): *"현재 이 청동촛대는 보물로 지정되어 있습니다... 국가에서 보물로 지정하고 있습니다."*
  → 지정 안 된 유물을 지정됐다고 확신에 차서 오답
- `ssu003094`(요령식 동검, 미지정): *"국보로 지정되어 있지 않습니다. 하지만 보물 제 1239-2번으로 지정되어 있습니다."*
  → **존재하지 않는 지정번호를 구체적으로 지어냄** (가장 위험한 유형의 hallucination)

## 결론

- 속도: 세 모델 다 3.5~4.4초로 실서비스에 쓸 만한 수준, 큰 차이 없음
- 사실 언급률: EXAONE이 재질·시대를 가장 잘 언급함 (64%/71%)
- **Hallucination**: EXAONE, Qwen2.5(직접 양자화) 둘 다 미지정 유물에 대해 정직하게 답한 반면,
  **Llama 3.1은 존재하지 않는 지정번호까지 지어내는 등 grounding 실패 사례가 나옴**
- 현재 EXAONE 선택을 유지하는 것이 타당해 보이며, Qwen2.5(직접 양자화)는 Apache 2.0
  라이선스가 필요해지면 대안으로 쓸 만함. Llama 3.1은 이번 결과 기준으로는 비추천.
